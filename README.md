# mol-diffusion

A 2D molecular diffusion model built as a learning project to understand how RFDiffusion and structure-based drug design work from first principles.

---

## Motivation

Modern protein and molecule design uses diffusion models — the same class of models behind image generators like Stable Diffusion — but operating over 3D atomic coordinates instead of pixels. RFDiffusion (Baker lab, 2023) generates novel protein backbones by learning to denoise backbone frames in SE(3) space. DiffSBDD generates drug candidates conditioned on a protein binding site.

This project builds the same ideas in 2D with small molecules, where everything is inspectable and trainable on a laptop. The goal is concrete intuition for:

- Why Gaussian noise is the right corruption process
- What message passing actually computes and why graph structure encodes physics
- How the denoising objective connects to valid molecular geometry
- How conditioning (on scaffolds, binding sites, molecular properties) extends the unconditional model

---

## Background

### Why Diffusion?

Earlier generative approaches (GANs, VAEs) either required an adversarial training game that frequently collapsed, or collapsed to a single average output. Diffusion reframes generation as a sequence of small, supervised denoising steps — many easy problems instead of one hard one.

The mathematical justification comes from non-equilibrium thermodynamics: if a forward noise process adds small Gaussian increments, the reverse process is also approximately Gaussian at each step, and a neural network can learn its parameters. Gaussians are closed under addition, so you can jump to any noise level t in a single operation during training without simulating all intermediate steps.

### From Images to Molecules

In image diffusion, the state is a pixel grid. Noise corrupts pixel values. The denoiser is a U-Net that predicts the added noise given a noisy image and timestep.

In molecular diffusion, the state is a set of atomic coordinates. Noise corrupts atom positions. The key differences:

| Images | Molecules |
|---|---|
| Fixed grid (512×512) | Variable number of atoms per molecule |
| No structural prior between pixels | Bond graph encodes which atoms are coupled |
| Any pixel arrangement is valid input | Bond lengths and angles must satisfy chemistry |
| U-Net denoiser | GNN denoiser (graph structure is the inductive bias) |

For 2D molecules, the forward process adds Gaussian noise to (x, y) coordinates:

```
coords_t = sqrt(ᾱ_t) * coords_0  +  sqrt(1 - ᾱ_t) * ε,   ε ~ N(0, I)
```

where ᾱ_t follows a schedule from 1 (clean) to 0 (pure noise) over T steps. The bond graph is never noised — only positions. The network sees noisy coordinates + the fixed graph and predicts ε.

### Physics Constraints

Valid molecules have:
- **Bond lengths** near a fixed normalized value (~1.0 after normalization), with very low variance
- **Bond angles** clustering at discrete values determined by orbital hybridization:
  - ~60°: 3-membered rings (epoxides, cyclopropanes)
  - ~109.5°: sp3 carbon (tetrahedral), 5-membered rings
  - ~120°: sp2 carbon, aromatic rings (dominant in drug-like molecules)
  - ~180°: linear bonds (triple bonds)

These are the distributions the trained model should reproduce at inference. A denoising step that violates them — producing a bond length of 2.0 or an angle of 45° — is physically wrong.

## Dataset

1,913 approved small molecule drugs fetched from ChEMBL (max_phase=4, small molecules only). Filtered to:
- 4–50 heavy atoms (hydrogens removed)
- Single connected components (no salts or mixtures)
- Valid RDKit SMILES parse

2D coordinates generated by RDKit's coordinate layout algorithm, which places atoms using chemistry-aware heuristics (regular hexagons for aromatic rings, tetrahedral geometry for sp3 centers). All coordinates normalized so mean bond length = 1.0 across the dataset.

Observed constraint distributions:
- Bond lengths: spike at 1.0, std = 0.048
- Bond angles: dominant peak at 120° (43k angles, aromatic rings), secondary at 109° (6.5k, sp3/5-rings), small peak at 60° (700, 3-membered rings)

## Architecture

### Why a GNN

The denoising network needs to handle variable-size molecules and respect bond structure. An MLP flattening all coordinates treats the molecule as a flat vector with no structural prior — the network must learn from scratch which input dimensions are correlated (i.e., which atoms are bonded). A GNN hardcodes the dependency structure via edges: atom i only directly influences atom j if they are bonded. The network only needs to learn *how* bonded atoms influence each other, not *which* ones do.

### Message Passing

At each layer, every atom aggregates information from its bonded neighbors, updates its hidden state, then the process repeats. After k layers, each atom's representation encodes its k-hop neighborhood.

```
# One message-passing step at atom i
messages = [MLP([h_i, h_j, edge_ij])  for j in neighbors(i)]
aggregated = sum(messages)
h_i_new = MLP([h_i, aggregated])
```

This encodes physics through structure:
- **Bond lengths**: atom j passes its current position to atom i. Atom i learns to predict noise that keeps it ~1.0 away from j.
- **Bond angles**: atom i aggregates from all neighbors simultaneously. The multi-neighbor context lets the network reason about the angle between two bonds at atom i.
- **Ring systems**: after 3 hops, every atom in a 6-membered ring has seen every other atom in the ring. The network can denoise the whole ring as a unit, converging to a regular hexagon collectively.

### Full Architecture

```
Input:
  atom features: [x, y, one_hot(atom_type), sinusoidal(t)]
  edge features: [one_hot(bond_type)]

3–4 x MessagePassing layers (hidden dim ~128)
  → ReLU + LayerNorm after each

Output head:
  MLP(h_i) → (Δx, Δy) per atom   [predicted noise]
```

~300k parameters. Trains in under an hour on M3 MPS.

### Training Objective

```python
t = random integer in [1, T]
noise = randn_like(coords)
coords_t = sqrt(alpha_bar[t]) * coords + sqrt(1 - alpha_bar[t]) * noise
predicted_noise = gnn(coords_t, graph, t)
loss = MSE(predicted_noise, noise)
# optional: + λ * bond_length_penalty(coords_t - predicted_noise)
```

## Conditioning

The unconditional model learns p(molecule). Conditioning extends this to p(molecule | constraint) by injecting a condition embedding at every message-passing layer:

```
h_i_new = MLP([h_i, aggregated, condition_embedding])
```

### Types of Conditions

**Fixed substructure (scaffold)**
Fix a subgraph with known coordinates. During reverse diffusion, clamp those atoms back to their target positions after every denoising step. The fixed atoms exert geometric pressure on their bonded neighbors through message passing. Free atoms denoise around the scaffold. This is how RFDiffusion handles a binding site: the target protein is clamped, the designed binder is free.

**Global molecular properties**
Encode MW, logP, ring count, heteroatom flags as a vector. Inject as condition. The model learns to denoise toward molecules matching those properties. Useful for enforcing Lipinski drug-likeness rules.

**Binding site geometry**
Represent the binding pocket as a point cloud with chemical features (hydrophobic, H-bond donor/acceptor, charged). Use cross-attention to let each molecule atom attend to nearby pocket points:

```
cross_attn = CrossAttention(query=h_atom, key=h_pocket, value=h_pocket)
h_i_new = MLP([h_i, aggregated, cross_attn])
```

Each atom now knows which pocket features it's near and learns to denoise toward geometrically compatible positions. This is the structure-based drug design (SBDD) setup, equivalent to what DiffSBDD does.

### Classifier-Free Guidance

Drop the condition with probability ~20% during training, replacing with a null embedding. At inference, run both conditional and unconditional denoising and extrapolate:

```
noise_guided = noise_uncond + scale * (noise_cond - noise_uncond)
```

Higher scale = stronger constraint adherence, less diversity. The same mechanism as the CFG scale in Stable Diffusion.

## Extension Path

```
Step 1 (current):  unconditional GNN denoiser
                   learns p(valid 2D molecule)

Step 2:            condition on atom count + atom types
                   guarantees output has the right composition

Step 3:            fixed scaffold clamping
                   drug scaffold / core structure design

Step 4:            binding site cross-attention
                   full structure-based drug design
```

Each step adds one condition type. The noise schedule, denoising loop, and loss function stay the same throughout.

## Connection to RFDiffusion

This project is a 2D analogy to RFDiffusion. The differences in production:

| This project | RFDiffusion |
|---|---|
| 2D (x, y) coordinates | 3D SE(3): position + orientation per residue |
| Small molecules, bond graph | Protein backbone, sequence graph |
| Gaussian noise on R² | Gaussian + IGSO(3) noise on SE(3) |
| GNN message passing | RoseTTAFold architecture |
| ~2k training molecules | ~57k PDB structures |
| Soft constraint penalties | Torsion angle parameterization (hard constraints) |
| Conditions: scaffold, properties | Conditions: binding hotspots, symmetry, secondary structure |

The core loop — corrupt with noise, train a network to predict that noise, sample by running the reverse process — is identical.
